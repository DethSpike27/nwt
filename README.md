# 📖 NWT Bible Reading Tracker

A simple, single-page web app to track your Bible reading progress through the NWT Study Bible.

## ✨ Features

- 📚 All 66 books of the Bible organized into reading portions (~29 verses each)
- ✅ Check off portions as you read them
- 📊 Progress tracking per book and overall
- 🔥 Consecutive reading streak counter
- 🌙 Dark / Light mode
- 🌐 English / French language support
- 💾 Export & Import your progress as a JSON backup
- 📱 Responsive design (mobile-friendly)

## 🚀 Usage

Visit the live site: **[https://YOUR-USERNAME.github.io/nwt](https://YOUR-USERNAME.github.io/nwt)**

Or open `index.html` directly in your browser — no server required.

## 💡 How to deploy on GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings** → **Pages**
3. Under **Source**, select `main` branch and `/ (root)` folder
4. Click **Save**
5. Your site will be live at `https://YOUR-USERNAME.github.io/REPO-NAME`

## 🔒 Privacy

All reading progress is stored **locally in your browser** (localStorage). No data is sent to any server.
